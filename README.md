CYBERSECURITY CHATBOT

DESCRIPTION: This project is a C# chatbot app that is designed to inform users of basic cybersecurity concepts. The chatbot simulates a simple text-based conversation using typing bubble effects and structured user-interface.

FEATURES: The chatbot plays an audio greeting and display a ASCII logo as a header upon launch. The chatbot then initiates conversation with the user and prompts input from the user. The chatbot responds to input in a friendly manner that ensures that the conversation is flowing between the two parties. The chatbot has a memory feature to recall the last topic of conversation and is capable to divulge further information regarding a chosen topic if requested by the user.

TECHNOLOGIES USED: C# WPF application Visual Studio 2022

HOW TO RUN THE PROJECT:
1. Open the project in Visual Studio 2022
2. Make sure that the following files are included:
  ascii-text-art.txt
  cyberbotGreeting.wav
3. Run the program
